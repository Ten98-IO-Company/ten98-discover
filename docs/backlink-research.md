# Backlink research contract

This bounded P52 increment adds two fixed DataForSEO Backlinks reports to the existing browser-only [domain research](domain-research.md) quote, explicit Start, job and receipt flow. It is not full P52/P49 parity or live-provider acceptance. No dependency or migration is added. Organic requests and stored organic reports retain their existing shapes and scope rules.

## Requests and target scope

The strict union lives in `src/server/backlink-research-input.ts`. Both reports require `connectionId`, `target`, `scope`, `status` (`live`, `lost`, `all`) and `report`. `backlinks_overview_v1` requires `limit:1`. `backlinks_profile_v1` requires `limit:25|50|100`, `offset:0..20000` divisible by limit, `follow:all|dofollow|nofollow` and `order:rank_desc|first_seen_desc|last_seen_desc`; optional `sourceHost` is an exact canonical public hostname. Google location/language, custom filters/endpoints and continuation tokens are rejected. Inputs remain at most8192 bytes at the native route.

Host scopes accept only a hostname or root URL. IDNs use ASCII; leading `www.` is removed as required by the provider's domain-target contract. `domain` selects that exact host; `subdomains` includes descendants. URL scopes require absolute HTTP(S), no credentials/port/query/fragment. `exact_url` preserves scheme, hostname including `www.`, path and trailing slash. `subfolder` preserves scheme/host, removes trailing slashes and covers that path, its query variants and descendant paths; root folders are rejected. Canonical requests are shown before payment. No target is fetched or DNS-resolved.

Folder filtering adapts the pinned OpenSEO boundary pattern with escaped LIKE literals and independent returned-URL checks. It uses three scope conditions plus at most two user filters, below the provider's eight-condition ceiling. See the complete upstream MIT notice in [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md). Exact backlink semantics must not inherit organic HTTPS/www/query equivalence.

## Fixed provider contracts

Contracts were inspected2026-10-16. [Summary Live](https://docs.dataforseo.com/v3/backlinks-summary-live/) receives explicit `include_indirect_links:false`, `exclude_internal_backlinks:true`, `rank_scale:one_hundred`, status, scope and a receipt tag. Folder `backlinks_filters` restrict the aggregate population. The saved single summary row retains provider counts, spam score and dates. Folder rank remains unavailable because the API does not establish a distinct folder rating. Missing values remain null; measured0 stays0. `returnedCount:1` denotes one summary record, never one backlink.

[Backlinks Live](https://docs.dataforseo.com/v3/backlinks-backlinks-live/) uses fixed `mode:as_is`, external links, explicit status/rank scale, one requested page and a stable field ordering. Target-scope, source-host and follow predicates are sent before paging and independently checked on every returned row. Only direct in-scope target URLs pass; exact root URLs include their equivalent bare-host spelling. The API supplies the highest-ranked backlink per referring page; `totalCount` describes those records, while `linksCount` retains page multiplicity. Raw source/target URLs and domains are retained for link identity. Results also retain provider link/page/domain ranks, flags, anchor and observation dates. Retrieval time is not an index-freshness guarantee.

Each page/filter change is a new draft requiring its own quote and explicit Start. No automatic paid pagination occurs. A receipt with offset greater than0 remains `limited:true`, including its last page; a later empty page may be valid if the index changed. Separate requests are separate snapshots and cannot establish a single consistent crawl. Deep paging beyond offset20000, history, anchors, referring-domain tables, competitors, link-level alias deduplication (P80) and broader filtering remain unfinished. Counts from overlapping alias summaries must never be added as a deduplicated total.

DataForSEO rank is named and uses0–100. It is neither Ahrefs Domain Rating nor Semrush Authority Score. Ahrefs remains a separate unimplemented integration: the current [free API contract](https://docs.ahrefs.com/en/api/reference/public/get-domain-rating-free) requires an APIv3 key and carries the [Domain Rating license](https://ahrefs.com/legal/domain-rating-license). No keyless fallback or computed substitute is implemented.

## Price, identity and retention

The free [User Data](https://docs.dataforseo.com/v3/appendix/user_data/) account response supplies `price.backlinks.summary.live.priority_normal` or `price.backlinks.backlinks.live.priority_normal`. Exactly one per-request and one per-result unit are required. The ceiling is base plus limit times per-result; missing/unsupported units block quoting. Published prices are never fallback values. The worker repeats the account/price check, then rechecks current role, connection revision, quote expiry and shared per-connection cap before one paid dispatch. The master pause and unknown-charge safeguards apply; no aggregate app budget or seat restriction is added.

Backlinks require no Google market catalog. All four roles can read; owner/admin/editor can quote and Start. Reconciliation stays owner-only. Original account fingerprint and exact endpoint/profile/page/filter/tag metadata must match the free [Backlinks ID List](https://docs.dataforseo.com/v3/backlinks-id_list/) result within28days. Labs ID List is never a fallback. Ambiguous or truncated inventories leave spending paused. A malformed result with verified financial evidence retains its charge; an interrupted or unidentified task remains unknown and is never automatically resent.

Migration0048 JSON request/result storage, the no-retry queue, lost-dispatch recovery, restore handling and existing retention all apply unchanged. Financial receipts and request identity survive purged content. GET `/domain-research/runs/:id/export` rechecks current membership/retention and returns the exact saved page as bounded native JSON `{role,run,csv,rowCount}`, never a new provider request. JSON/CSV are bounded to2MiB; provider transport to4MiB. Oversized content fails explicitly rather than truncating. CSV preserves target, scope, filters, offset, source, retrieval and metric meanings, with existing formula escaping.

## Source verification

`tests/backlink-research.test.ts` contains pure boundary/price/parser/transport checks. `tests/backlink-research-integration.ts` is an opt-in, fresh local database runner for actual native authorization, jobs, receipts, caps, reconciliation and retention with an in-memory synthetic provider. Neither synthetic responses nor authored checks establish live entitlement, billing or index completeness. Execution evidence must be recorded separately by the supervising runner; this document makes no passing-test claim.
